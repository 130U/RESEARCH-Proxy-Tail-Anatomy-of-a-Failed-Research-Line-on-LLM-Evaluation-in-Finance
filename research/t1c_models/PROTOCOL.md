# T1C frozen protocol

Frozen before the first model response, 2026-11-16 America/New_York.

- Inputs: T1 commit `30acb8d`; official FinQA commit `0f16e2867befa6840783e58be38c9efb9229d742`, public test. All 196 T1 `witnessed_outside` questions, matched without replacement to 196 `certified_inside` questions by the five T1 operation categories. Sort IDs, shuffle within category using Python Random(20261116), pair, then shuffle the 392 calls. Selection never uses model responses.
- Each call is a fresh `fork_turns=none` agent session. The fixed prompt contains the original table, pre/post text and question only, with no labels, gold program, T1 information, group or benchmark ID. One response per question, inherited runtime model/effort, no paid API or training. A second model is optional and will only be reported if actually run. No external tools or sources for solving. No model retry based on correctness; malformed responses are retained and flagged.
- Record original response verbatim and orchestration metadata. Evaluate both the reported number and the re-executed expression. The latter is essential: official FinQA evaluates a program, not the number of decimal places a model happens to print. Never describe losses caused only by printing fewer digits as input-rounding errors.
- Three rules: official final `round(value,5)==qa.exe_ans`; absolute relative error <= 1% of nonzero gold (exact equality for zero); and rounding to the human answer's displayed decimal places, with declared percent scaling. Human/execution label disagreements and missing human answers are reported separately. Units are normalized independently of correctness, not by trying alternative factors until an answer passes.
- Interval attribution: T1's outer enclosure is only a screening condition. Certify actual attainability through exact rational corner evaluations and a continuous path whose endpoint outputs bracket the model value, with interval checking of all divisions along the whole input box. Failed certification remains unresolved. This is compatibility with T1's independent rounding-box assumptions, not full-document validity.
- For every failed answer, keep separate flags for attainable output, alternative documented precision, a reasonable alternative interpretation, real extraction/arithmetic/reasoning error, output quantization, and reference inconsistency. These are not mutually exclusive numerical facts. Primary causal attribution requires a reasonable expression and source support; accidental interval hits by erroneous expressions do not prove a correct answer was marked wrong. Another agent reviews disputed interpretations and true errors, with disagreements retained.
- Report witness/control error-rate difference and 95% percentile interval from 10,000 bootstrap draws over document/page clusters, retaining all questions on a sampled page together. Repeat each rule for printed answers and executed expressions; report different display-rule availability denominators. Matching is by operation only and is observational, not causal. No claim that training contamination necessarily affects the two groups equally.
- Precision budget: report emitted significant digits and a conservative relative-error budget from the exact gold-program output range (or a proven outer bound), and the T1a first-order formula where its structural conditions apply. State the convention and exclude zero/signed-crossing outputs from meaningful-digit claims.
- Decision threshold from task: witness error exceeds control by >5 percentage points and the cluster interval excludes zero, OR >10% of rejected answers are document-consistent. Report the literal box-compatible version and the stricter source-supported causal version separately. A literal threshold crossing alone cannot establish input-rounding-caused benchmark noise.
