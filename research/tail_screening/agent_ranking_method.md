# 128-item blind ranking trial with isolated model sessions: what it can measure

2026-11-16. Uses only the outputs of isolated model sessions; no model is trained. This memo supports one finite-sample feasibility experiment.

**This design can measure how much of the top of a reference ranking is kept by another ranking, and how sensitive the result is to reordering the input; it cannot be used to validate an asymptotic widening law.** The output uses ordered groups, where items in the same group are ones the model could not reliably distinguish. Self-reported numbers such as "0.97" or "8.6 points" are not token logprobs, and they do not thereby become calibrated probabilities.

In Qin et al., *Large Language Models are Effective Text Rankers with Pairwise Ranking Prompting* (Findings of NAACL 2024), §3.1 asks twice for each document pair with the input order swapped, and records a tie when the two preferences disagree; §3.3 also explicitly acknowledges that pairwise comparisons are not necessarily transitive. So pairwise comparison is not a tool that is automatically immune to order bias, and contradictory comparisons cannot be treated as a strict total order. §2.2 of that paper discusses order inconsistency and missing outputs in listwise ranking. This experiment can borrow the "keep ties" treatment, but does not adopt its rule of falling back to the initial ranking when final scores are tied, since otherwise input position would re-enter the output. [Original paper, §§2.2, 3.1–3.3](https://aclanthology.org/2024.findings-naacl.97.pdf).

In Tang et al., *Found in the Middle: Permutation Self-Consistency Improves Listwise Ranking in Large Language Models* (NAACL 2024), §2.2 randomly shuffles the same candidate set under a fixed instruction and then aggregates the output rankings; §3.2 studies position bias. This directly supports the need to "rerun with the same prompt and a changed input order". However, its aggregation theory and repeated experiments cannot imply that "the two permutations in this run have already removed the bias". Two runs are enough to detect obvious instability; two agreeing runs also cannot prove that all permutations agree. These papers study ranking tasks; the size of the bias on the financial texts in this run still has to be measured. [Original paper, §§2.2–2.3, 3.2](https://aclanthology.org/2024.naacl-long.129.pdf).

We recommend fixing two independent random permutations $`\pi_1,\pi_2`$ first, with both model tiers reading the same pair of permutations, giving four "model × order" runs; the instruction, sample content and output format are identical. Each run uses an independent clean context, hiding human labels, the outputs of other runs and the hoped-for conclusion; sample IDs are only for locating items. "Independent" here refers to run isolation and the way the permutations are generated, and **does not mean that the model errors are statistically independent**. If decoding randomness cannot be fixed, the difference between two outputs contains both the order effect and run-to-run fluctuation; it can only be reported as repeat-run sensitivity and cannot be attributed to a pure position effect.

First compare the top-list overlap between two runs of the same model, then interpret the between-model overlap and widening curves. If the same-model change under reordering is already comparable to the cross-model difference, the cross-model result is not enough to attribute to the model tier. Do not pick from the four combinations the one that best supports the expectation; keep the main comparison and the range of results over all repeat runs. This range is this run's sensitivity, not a confidence interval formed from four independent datasets. The model types and configurations must be identifiable: if the two agents actually call the same model with the same configuration, they are same-model repeats, not a cheap and an expensive model; even if they are indeed different models, without comparable cost records they can only be called two model configurations.

For rankings without ties, let the reference model's top $`k`$ items be $`A_k`$ and the candidate model's top $`m`$ items be $`B_m`$, and define

```math
\widehat R(k,m)=\frac{\left\vert A_k\cap B_m\right\vert}{k},\qquad
\widehat q_\gamma(k/128)=\frac{\min\{m:\widehat R(k,m)\ge\gamma\}}{128}.
```

The widening factor is just $`m/k`$. These quantities depend only on sets and order, so they need no continuous scores, probability calibration or logprobs; strictly monotone transformations also do not change the results. The negative tail is computed in the same way with the ranking reversed. They are descriptive quantities for these 128 samples under this reference ranking; they are neither recall of true financial value nor an out-of-sample recall guarantee. Listwise rankings may also depend on the whole candidate set, and cannot pose as a continuous score that is intrinsic to each text and does not change with the candidate set.

With ties, the main result can be computed only at the boundaries of complete ordered groups, using the actual $`k/128`$, $`m/128`$; this makes the curve coarser but keeps the true resolution. If fixed $`k,m`$ must be shown, report the minimum and maximum recall over all admissible choices of the boundary ties on the reference side and the candidate side, and give the widening range from these. Do not force-break ties by ID or input position and then report only one number. If the 128 items are split into small batches that are not compared with each other, the local ranks within each batch also cannot be stitched directly into a global top-k.

With 128 items, the 1% tail has only about 1–2 items and 2% only about 2–3; even with $`k=8`$, the minimum step of recall is still 12.5 percentage points, and the 90% target in fact requires recovering all 8. The curve should be reported with an explicit $`k`$ and the actual fraction, to avoid dressing up integer rounding as an exact "1% tail". The two input permutations add repeats of the ranking measurement; they do not turn the sample size from 128 into 256, and four runs also do not become 512 independent financial events.

So what this round can deliver is a finite-$`p`$ curve with tie handling and reordering sensitivity, together with a judgment on "whether the ranking resolution is sufficient and whether between-model differences exceed same-model fluctuation". A conditional-extremes law as $`p\to0`$ needs enough tail observations as the sample grows, with threshold and estimation error under control; a fixed 128 items carry no such information, and fitting a log–log straight line cannot provide it either. The asymptotic $`\alpha`$ is not estimated here, and the difference of the candidate model relative to the reference model is not called a true model-quality gap.
