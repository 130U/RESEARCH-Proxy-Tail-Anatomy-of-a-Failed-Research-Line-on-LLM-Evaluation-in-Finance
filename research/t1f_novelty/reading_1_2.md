- Lu Ji, Zhou Li (2010), "A study of methods for automatically adjusting report data in computerised accounting" (Chinese-language paper, title translated), *China Management Informationization* 4:11–15, DOI 10.3969/j.issn.1673-0194.2010.04.004: a reprinted abstract/opening was found, but the complete original was not obtained. It describes automatically adjusting rounded statements so that they balance; one cannot conclude from this that it computed the feasible region of the pre-rounding true values. Evidence level: abstract / second-hand reprint.
- Accessing the native Scholar and Semantic Scholar search pages returned no results; only `site:`-restricted web searches were completed. The overall novelty conclusion keeps this coverage gap.
- Not all post-2023 citing papers of FinQA, TAT-QA and ConvFinQA were exhausted. The follow-up work read is only a traceable set of hits.
- HTTPS access to Dandekar's original site timed out / had a certificate mismatch; HTTP download from the public original site succeeded. The saved local reading copy and two page images are only reading evidence; there is no need to publish another author's whole PDF with the GitHub report.
